# Austausch

Dateien zum Laden auf den Arbeits-PC.

## Herunterladen (ohne Git)

Das Repo ist privat: erst im Browser bei github.com anmelden, dann den Link öffnen.

**ZIP:** https://github.com/ralphdenk0209-debug/austausch/archive/refs/heads/main.zip

Entpacken, dann den gewünschten Ordner nach z. B. `C:\Werkzeuge\` kopieren.

## Inhalt

| Ordner | Was |
|---|---|
| [Playwright-Werkzeug](Playwright-Werkzeug/) | Teams-Folien → OneNote, Browser-Abläufe, Screenshots, PDFs, Seiten prüfen, Tabellen → Excel. Start: `START.bat`, Anleitung: `ANLEITUNG.html` |

## Aktualisieren

Neues ZIP laden und die Dateien über den alten Ordner kopieren. Eigene Sachen bleiben erhalten, wenn du **`einstellungen.json` nicht überschreibst** (und `Mitschnitte`, `Ablaeufe`, `Ergebnisse`, `anmeldung.json` liegen lässt).
